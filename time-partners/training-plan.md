# 50+时间伙伴培训方案

试用稿。供《老年照护90课》与社区试点使用。

本方案只培训非医疗的日常互助。洗澡、翻身、喂药、注射、压疮和病情判断不在时间伙伴权限内，转专业照护。小时数不能代替资格。

已经确定的两条制度：时间属于贡献者本人；不是到了某个年龄才能用，而是本人真正需要时就能用。50+指开始建立照护储备的人，不是“50岁就是老人”。

## 1. 目的与适用

### 1.1 目的

- 让50岁以上、仍有余力的居民，能安全、稳定地为社区老人提供生活互助。
- 用同一套课，把《老年照护90课》和《50+时间伙伴》接上：课程给方法，时间账户给记录。
- 把“能做什么”和“记多少小时”分开。权限由培训和考核决定。

### 1.2 适用

- 对象：本社区常住、年满50周岁、身心能够完成所选服务的居民。未满50周岁、愿意参与的人可旁听，试点阶段不单独开账户。
- 服务：陪伴、家务协助、陪同外出、提醒服药时间、短期看护让家人休息。
- 不做：医疗护理、身体护理、财务代管、法律意见、心理治疗。

### 1.3 三条培训原则

- 一起做，不替做。本人还能做的，陪着做，不抢过来做完。
- 见面才派单。线上看课不能代替社区见面。
- 单外不做。第一次上门前写清内容；单上没有的，不做，也不记小时。

## 2. 级别与权限

只设两级开放、一级关闭。不把护理编进时间伙伴。

| 级别 | 可以做 | 训练量 | 见面 |
| --- | --- | --- | --- |
| L1 陪伴与家务 | 聊天、散步、读报、陪买菜、简单整理、倒垃圾、陪吃饭 | 必修3课 + 线下90分钟，情景两题通过 | 协调员15–20分钟见面 |
| L2 生活协助 | 陪诊排队、协助出行、提醒服药时间、餐食加热、短时看护让家人休息 | 再加4课 + 线下90分钟，情景两题通过 | 协调员 + 1名已服务伙伴 |
| 关闭 | 洗澡、翻身、导尿、压疮、注射、喂药、判断病情、保管银行卡和密码 | 不开放 | 转专业人员或家属 |

L1未通过，不能单独上门。L2未通过，只能继续做L1。有300小时也不能升到关闭项。专业人员若做健康科普、心理或法律，另交资质，不进时间账户。

## 3. 从报名到第一次上门

| 步骤 | 谁做 | 做什么 | 通过才进入下一步 |
| --- | --- | --- | --- |
| 1 报名 | 申请人 | 实名、常住地址、紧急联系人、可服务时段、拒绝事项 | 信息齐全 |
| 2 身份核对 | 社区协调员 | 核对常住、紧急联系人；不宜接触老人的情形不接收 | 核对完成 |
| 3 必修课 | 申请人自学 | 3课，约90分钟，可反复看 | 看完并记下两道边界题 |
| 4 见面 | 协调员 | 15–20分钟，不考护理，只看动机、边界和稳定性 | 边界题答对 |
| 5 线下练习 | 社区，每月一次 | 90分钟情景，两人一组 | 两题通过 |
| 6 保险 | 组织 | 第一次上门前买妥意外险 | 保单在档 |
| 7 配对会 | 三方 | 伙伴、老人或家属、协调员，写清内容和时段 | 服务单签字 |
| 8 见习两次 | 协调员在场或电话可通 | 前两次不独立；结束签字，48小时内回访 | 回访无异议才入账 |

北京时间银行的顺序是申请、培训、再服务，并由街道或居委会就近组织。圣加仑是培训之后配对，见面谈定内容，每次服务回报并签字才入账。本方案沿用这两条，不采用抢单。

## 4. 课程

课从《老年照护90课》抽取，不新开一套长课。每课仍按约5分钟讲解，线下只做情景。手机可看，社区每月一次集中练习。

### 4.1 必修三课：所有人

| 课 | 讲什么 | 必须带走的一句话 |
| --- | --- | --- |
| T1 我的时间 | 1小时记1小时；只记本人；不能转、卖、提现、继承；现在需要就能用；没贡献过的人靠公共帮助，不扣别人的小时 | 时间不是积分，是一份以后的社区支持 |
| T2 一起做 | 家是生活不只是房子；还能做的不替做；尊重原来的习惯和喜好 | Do with, not do for |
| T3 停下来 | 跌倒、喘不上气、突然糊涂、对方拒绝、家属争执：停止服务，叫协调员或急救，不自己处理 | 不会处理，就不要处理 |

### 4.2 L1 加两课

| 课 | 讲什么 | 练习 |
| --- | --- | --- |
| T4 进门与离开 | 预约才去；自我介绍；不收礼、不借钱、不评家人、不拍照发朋友圈；离开前把用过的东西放回原处 | 模拟进门三分钟 |
| T5 陪伴怎么停 | 沉默可以；不追问病情和家事；对方想结束就结束；超时不硬留下 | 老人说“你再坐会儿，我给你看存折” |

### 4.3 L2 加四课

| 课 | 讲什么 | 练习 |
| --- | --- | --- |
| T6 陪诊 | 只排队、陪同、记录家属交代的问题；不解释检查结果；不替签知情同意 | 医生问你意见，你怎么说 |
| T7 药 | 只提醒时间；药在本人或家属手里；不喂、不分装、不建议换药 | 老人说“你喂我这颗” |
| T8 把动作交还 | 切之前问一句：您要自己来，还是我在旁边？做完不表扬成“你真不行” | 老人说“你帮我做完吧” |
| T9 看护边界 | 短时看护是让家人休息，不是替代夜班护理；约定结束时间；超时叫协调员 | 家属临时说再留三小时 |

### 4.4 线下90分钟怎么排

- 0–10分钟：点名，确认已看完对应课。没看完的旁听，不参加当次考核。
- 10–25分钟：协调员示范一题，只示范停下来和交还动作。
- 25–70分钟：两人一组，各做两题。一人做，一人记：有没有替做、有没有越界、有没有停下来。
- 70–90分钟：反馈。不过的人下次再来，不在群里点名。

记录四项：课名、日期、时长、考核人与结果。没有记录，不能派单。

## 5. 见面，不叫面试

见面不是招聘，也不考专业知识。地点在社区站点，15到20分钟。一个人只面一次；升L2时加一场短的复核，约10分钟。

### 5.1 问四件事

- 为什么来，能不能连续做三个月，而不是只来一次。
- 接受哪些服务，拒绝哪些。拒绝洗澡和医疗是对的，不加分也不减分。
- 家里有没有正在照顾的人。有，就限制每周时数，避免两边耗尽。
- 情景一句：老人把银行卡给你，你怎么说。答“帮你收好”的，先不派单，回炉T4。

### 5.2 不面的

- 不看学历、职业、收入。
- 不当场考护理操作。
- 不要求背政策原文。

### 5.3 不接收的情形

- 不能说明紧急联系人。
- 明确要求管钱、管药、管银行卡。
- 近期与服务对象有经济纠纷，或被社区核实不宜单独接触老人。
- 不能接受“单外不做”和回访。

未通过的人书面或短信告知结果，感谢，并建议旁听课程。不公开原因细节。

## 6. 情景考核题

每级从下面抽两题。答到“停、交还、叫人”即通过；答到替做、收礼、解释病情、留下银行卡，即不通过。

| 题 | 对方说 | 通过的做法 |
| --- | --- | --- |
| 存折 | 你帮我收着，密码是…… | 不接。请对方自己收好，告诉协调员 |
| 红包 | 今天辛苦了，拿着 | 不收钱物。谢谢，小时已由服务单记录 |
| 替做 | 你帮我做完吧，我坐着 | 先问哪一步自己来；能做的一起做 |
| 喂药 | 你喂我这颗 | 不喂。提醒时间，药由本人或家属处理 |
| 病情 | 这个检查是不是癌 | 不解释。把问题记给家属或医生 |
| 加班 | 我家人还没回，你再留三小时 | 不私自延长。联系协调员改单 |
| 拍照 | 拍一张发群里，让大家看看 | 不拍、不发。离开后也不讲述可识别的家事 |
| 争执 | 家属当着老人说他老糊涂 | 不站队、不评。结束本次，报告协调员 |
| 跌倒 | 起身时滑倒 | 不硬拉。看反应，叫急救和协调员，留在旁边 |
| 拒绝 | 今天不想见你 | 马上离开。不劝、不记对方的过 |

## 7. 配对、见习、入账

### 7.1 配对会

第一次上门前必须有三方：时间伙伴、老人或家属、协调员。谈定并写在服务单上：做什么、不做什么、星期几、几点到几点、谁开门、谁签字、紧急电话。单外的事不做。

固定配对优先。一个人长期对一到两户，不每天换人。老人说不合适，换人，不扣任何一方时间，也不公开差评。

### 7.2 见习

- 前两次：协调员在场，或电话全程可打通。
- 结束时老人或家属签字，只确认“今天按单做了”，不打分。
- 协调员48小时内回访一次。无异议，小时入账。
- 两次见习后仍越界，退回L1练习，暂停派单。

### 7.3 什么时候升级给人

- 连续两次失约。
- 老人或家属拒绝继续。
- 出现跌倒、突然糊涂、喘不上气、家属争执。
- 对方要求管钱、管药、过夜。

升级后由协调员接手，伙伴不自己判断要不要继续。小时按已完成、已签字的部分记，未完成的不记。

## 8. 复训、暂停、退出

| 情形 | 动作 |
| --- | --- |
| 每12个月 | 复看T2、T3，线下再过一题。不过，暂停派单 |
| 服务中越界一次 | 回炉对应课，下一次由协调员在场 |
| 越界两次，或收礼、管钱 | 退出时间伙伴，已记小时保留但不派新单，直到复核 |
| 本人受伤或住院 | 账户可立即使用；停止派单，直到本人说可以再服务 |
| 搬离社区 | 停止派单。小时保留在本人账户，不转移、不折现 |
| 本人去世 | 未使用小时不继承。进入社区溢出账户，只给没有余额但已需要帮助的人 |

溢出账户不从别人的可用小时里扣。没有贡献过、但已经需要帮助的人，走公共帮助或溢出账户，不走“没积分就没服务”。

## 9. 谁负责什么

| 角色 | 负责 | 不负责 |
| --- | --- | --- |
| 时间伙伴 | 按单服务、按时到、签字、遇停即停 | 定资格、改服务单、解释病情、管钱 |
| 社区协调员 | 核对、见面、配对、回访、升级、记录 | 亲自承担全部照护、承诺小时一定能兑现 |
| 老人或家属 | 确认需求、开门、签字、临时变更加协调员 | 私下加时、给钱、要求越界 |
| 课程 | 提供T1–T9和情景 | 代替见面和保险 |

### 9.1 保险与记录

- 第一次上门前由组织购买人身意外保险。没有保单，不派单。
- 服务单、签字、回访、培训记录保存不少于服务结束后24个月。
- 前台只显示本人的已贡献、已使用、可用小时。后台同时显示社区已存小时和待兑现小时。

### 9.2 每周时数

试点阶段每人每周不超过4小时、同时不超过2户。家里已有照护任务的，每周不超过2小时。上限是为了持续，不是为了刷小时。个人账户总上限另案测算，参考圣加仑750小时，本方案不先定死。

## 10. 试点怎么开

- 第1个月：协调员2人先自己过T1–T5和见面提纲。
- 第2个月：招8–12名L1，只做陪伴和家务，只配对已同意试点的4–6户。
- 第3个月：其中通过见习、且愿意的人进入L2。L2户数不超过L1的一半。
- 满3个月复盘四件事：越界几次、回访不满意几次、小时是否入账及时、有没有人想管钱或加时。

复盘通过前，不做图片课宣发，也不把L2写成已开放的护理服务。

## 附录  服务单要写的字段

- 日期、开始与结束时间。
- 户址只写到楼栋和约定称呼，不在伙伴个人手机里另存病历。
- 本次只做的三件事。
- 明确不做：药、钱、洗澡、身体护理、拍照。
- 开门的人，紧急电话，协调员电话。
- 老人或家属签字，伙伴签字，协调员回访日期。
- 是否越界、是否中途停止。停止的，写叫了谁。

## 附录  见面记录四行

- 能连续做三个月：是 / 否。每周可做几小时。
- 接受的服务，拒绝的服务。
- 家中是否已有照护任务。
- 银行卡一题：通过 / 回炉。
