# 课程站

简单静态站，手机优先。

## 打开方式

1. 仓库 Settings → Pages
2. Source 选 Deploy from a branch
3. Branch 选 `main`，文件夹选 `/docs`
4. 保存后几分钟可访问

地址一般是：
https://pomosherry-hue.github.io/home-care-academy/

注意：私有仓库的 GitHub Pages 需要 GitHub Pro / Team。如果要公开给家属看，可以把仓库改成 Public，或另建一个公开仓库只放课程站。

视频来自 Releases 下载链接。私有仓库里，未登录的访客可能播不出视频。
